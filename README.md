# KinderFarms® Brand Command Center

A complete interactive brand command center for KinderFarms® — design system, master SKU catalog, competitor intelligence, retail distribution, and client-side design token asset vault. Powered by Next.js 14, Tailwind CSS, Three.js, and Recharts.

## Stack

- **Next.js 14** (App Router, static export ready)
- **Tailwind CSS** with the KinderFarms design token system
- **Three.js** (`@react-three/fiber`) for the interactive 3D flavor canister stage
- **Recharts** for clinical competitor analytics
- **Client-Side Master Data Engine** — Zero database credentials, 100% offline-ready and friction-free

## Run Locally

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
npm run start    # serve production build
```

## Features

- **Master Brand Architecture**: Monolithic master-brand view with interactive filtering across Hydration, Medicine, and Plus lines.
- **8-Flavor Seed Palette**: Interactive swatches with 1-click clipboard copy and real-time 3D canister preview.
- **Typography Specimen Studio**: Live sandbox for Tropiline Bold and geometric sans type scale.
- **Sub-Brand Migration**: Fast lookup for retired sub-brands (KinderLyte, KinderMed, KinderSprout).
- **Competitor Intelligence**: Head-to-head clinical sugar and osmolarity benchmarks against Pedialyte, Gatorade, and Liquid I.V.
- **Brand Asset Vault & Token Exporter**: Instant export in CSS Custom Properties, Tailwind v4 `@theme`, and JSON schema.
- **Zero Credentials Architecture**: No login walls, no environment secrets, and no external database dependencies required.
